# 情緒繪本書單

從文化部「中小學生讀物選介」第 42–47 次（2020–2025）獲選書單中，逐本篩選出 80 本以情緒為主題的繪本，依 10 大情緒主題分類，提供書名、適讀年齡、主題說明與評審推薦，作為親子共讀與班級閱讀的選書參考。
